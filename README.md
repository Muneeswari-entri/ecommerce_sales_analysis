# Ecommerce Sales Analysis using Excel

##Project Overview

This project analysis Ecommerce Sales data using Excel. Raw data

##Dataset

File:  Ecommerce_Sales_Dataset_updated  (4). x1sx
## Data Cleaning Steps Done
1. Removed duplicate rows
2. Removed blank rows
3. Fixed Date format to DD-MM-YYYY
4. Removed extra spaces using TRIM
5. Fixed Category names - Example: Electronics, electronic -> Electronics
6. Corrected negative Quantity and Price values
7. Removed rows where Order ID was missing
8. Created new columns: Total Sales, Month, Year

## Dashboard Created
- Total Sales, Total Orders, Total Customers
- Sales by Category
- Sales by Month
- Top 5 Products
- Top 5 Customers
- Sales by Region

## Key Findings
- Highest sales from Electronics category
- Sales increased in festival months
- Top customers contributed more repeat orders

## Tools Used
- Microsoft Excel
- Pivot Table, Charts, Slicers
